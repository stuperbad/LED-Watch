# tools/ - the layout pipeline and board checks

These scripts made and checked the revision A board. Most take the board file(s) as arguments; the ones that use KiCad's `pcbnew` module must be run with
`"C:\Program Files\KiCad\10.0\bin\python.exe"`, the router/geometry ones (`grid_route2.py`, `add_stubs.py`, ...) with a normal Python that has `shapely`, `numpy`, `Pillow`.

| Stage | Scripts |
|---|---|
| placement tidy-up | `mark_groups.py`, `mock_move.py`, `tidy_symmetry.py`, `mcu_area.py`, `bq_area.py`, `add_dummies.py`, `copy_positions.py`, `restore_cells.py`, `shrink_od.py`, `nudge_buttons.py`, `fix_flank.py`, `fix_back_ring.py`, `swap_j2_pogo.py`, `new_bz1.py`, `bz_nets.py` (helpers in `plc.py`) |
| routing | `polar_route.py` (LED rings: arcs + radial lanes), `grid_dump.py` -> `add_stubs.py` -> `grid_route2.py` (rip-up router) -> `merge_new.py`, `undangle.py`, `crystal_left.py` |
| re-routing a few nets (2026-10-15) | `reroute_prep.py` (delete the pieces that cross a chip's core, prune the tails), `arcs_to_segments.py`, then `grid_dump.py` -> `grid_route2.py --exclude` -> `merge_new.py`, then `fix_gnd_zone.py` and `prune_dangling_loop.py` / `prune_stub_vias.py` for stubs |
| revision B re-pin (2026-10-29) | `repin_sch.py` + `u1map.py` (rename the labels on U1's pin stubs in the saved schematic, no-connects for freed pins), `repin_pcb.py` (give U1's pads the new nets, set the revision), then `reroute_prep.py` -> `arcs_to_segments.py` -> `grid_dump.py` -> `add_stubs.py --via` -> `grid_route2.py --exclude` -> `merge_new.py` as above, `rip_net.py` (rip one net's copper near a point so it can be routed alone), `prune_leaves.py` (junction vias and tails left over from joining new routes to old copper; `trim_tails.py` is the earlier version) |
| keep-out clean-up (2026-10-29) | `reroute_rects.py` (like `reroute_prep.py` but for a list of rectangles, and arcs crossing them are deleted too), `zone_check.py` (which nets have copper inside a rectangle), `rip_net.py`; then the same router chain as above |
| exact-joint audit and repair (2026-11-04) | `check_joints.py` (does KiCad's U walk the whole net? model from KiCad's source: ends equal to the nanometre, via circle, pad position), `fix_joints.py IN OUT --snap 0.01 --include-ring` (copper-neutral repair: equal ends, nodes at T joints, ring arcs cut at vias; larger gaps only listed) |
| crystal zone / review checks (2026-10-29) | `check_angles.py` (sharp corners), `fix_angles.py` (cut them, arcs included), `zone_check.py` (copper inside a rectangle), `grid_route2.py --exclude "x0,y0,x1,y1@F,In1"` (keep tracks off only some layers), `verify_pins.py` (netlist against the datasheets: pin table, functions, voltage levels, currents) |
| breakout re-route (2026-10-30) | `rip_window.py` (cut the inner-layer lanes of a chip's nets inside a window, the rest stays), `rip_lanes.py` (rip whole nets' lanes), `add_escape.py` (straight escape lanes for fan-out vias), `grid_route2.py --prefer / --hist / --exclude` (preferred directions per layer, negotiated congestion, per-pad keep-outs), `prune_dangling_drc.py`, `remove_spur.py`, `octo_tidy.py` + `apply_tidy.py` (re-draw only the router's new chains with the fewest bends), `verify_pins.py` |
| ring LED stubs (2026-10-31) | `ring_extract.py` (list the F.Cu stubs of the S/M/H LEDs), `ring_stubs.py` (ROW pad: leave along the pad axis, then 45-degree steps to the lane via; sectors in parallel), `ring_col.py` (COL pad: one radial piece to the anode arc), `apply_ring_edits.py` (apply the edit files, straight pieces and arcs) |
| clean-up of vias / waists / hour links (2026-10-31) | `copper_dump.py` (copper of a board as JSON, arcs apart), `via_center.py` (track ends at via centres, short pieces out of vias), `close_gaps.py` (butted round caps), `col_links.py` (resistor to trunk at the hour ring), `apply_ring_edits.py` (also removes arcs) |
| pad exits of two-pad parts and ICs (2026-11-01) | `pad_exit.py` (traces leave the END of a pad along the component axis, then 45-degree pieces; `--ic U4` for a QFN: straight out of the package edge), `pad_dogbone.py` (moves a fan-out via onto the axis of its pad so pad, stub and via are in line) |
| finishing | `fix_gnd_zone.py` (ground plane to the board outline), `add_silk.py`, `silk_nodash.py`, `silk_thicken.py`, `silk_twoline.py`, `check_pad_entry.py --fix`, `dfm_gaps.py`, `drc_sum.py` |
| production | `make_bom_cpl.py` (position export -> JLCPCB BOM and CPL, with the rotation fixes) |
| older pipeline | `route_*.py`, `export_dsn.py`, `import_ses.py`, `prep_dsn.py`, `ses_keep_nonpolar.py` (the Freerouting round trip used for the 43.5 mm board) |
