How to make the next revision: change `REVISION` in `gen_schematic.py`, set the revision in the board's title block (File > Board Setup > Title block, or `pcbnew` python),
regenerate `production/` (commands in `../README.md`), commit, tag.

The git tag `rev-A` points at an old snapshot of A (2026-10-15, before the battery polarity fix); the real last state of A is the archive folder above. Tag `rev-B` when B is ordered.

Earlier attempts (43.5 mm board, wrist-strap lug experiments, X42) are in `../archive/boards/`.

**Code word `pogo-b`** = revision B with charge and program over the pogo row (before USB-C). Snapshot and notes: `../archive/boards/rev-B-pogo/`. Revision C (USB-C) is the main `LED Watch - Single Color.*` files since 2026-11-02; the file names did not change. The folder `mockups/` is the development history of C (save points, notes).
